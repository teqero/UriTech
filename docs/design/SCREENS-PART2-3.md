# UriGo - Design Reference (Partes 2 e 3)

## Parte 2 - Mobile User (páginas 1-11)

### Novos Serviços
- **Rastrear Família** - Localização de membros autorizados
- **Negócios Próximos** - Restaurantes, salões, cafés, ginásios
- **Cuidado Automóvel** - Lavagem, bateria, abastecimento, óleo
- **Assistência Estrada** - SOS com reboque emergencial

### UriPay Avançado
- Wallet com Carregar/Transferir/Sacar
- Histórico de transações
- Carregar UriPay com valores pré-definidos

### Escrow Seguro
- Pagamento protegido para compras em redes sociais
- Código de confirmação comprador/vendedor/entregador
- Taxa plataforma 1.5%

### Outros
- Notificações push
- Pedido Confirmado com referência URI-XXXXX
- Licitar para Serviços (canalização, electricidade, etc.)
- Funcionalidades IA UriGo

### Driver App (Parte 2)
- ESTOU ONLINE com ganhos do dia
- Aceitar/recusar pedido Taxi Premium
- Navegação com "Chegou ao Destino"

### Vendor App (Parte 2)
- Kero Kilamba dashboard
- Pedidos: Novos/Preparando/Prontos/Histórico
- Vendas do dia com % crescimento

## Parte 3 - Admin + Web (páginas 1-5)

### UriGo Admin
- Painel Operacional Luanda (tempo real)
- Finanças: gateways Multicaixa, Unitel, BAI, Pagasam, PayPal
- Módulos: UriTaxi, UriMoto, UriEnvio, UriLojas, UriMed, UriBeleza
- IA: preços dinâmicos, anti-fraude, suporte automático

### Web User
- Landing page com hero search
- Reservar viagem com seleção de veículo
- Tracking com steps (Confirmado → A Caminho → Entregue)
- Perfil com UriPay Wallet
