UriGo — Expo Go (Android)

Importante: corre sempre a partir de apps/mobile-user, não da raiz do projeto.
cd apps/mobile-user && npm run dev

Opção A — Wi‑Fi (mesma rede)

Telemóvel e PC na mesma Wi‑Fi. IP do PC:

exp://192.168.0.62:8084

Se der Failed to download remote update, abre o Firewall (PowerShell como Admin):

netsh advfirewall firewall add rule name="Expo Metro 8084" dir=in action=allow protocol=TCP localport=8084

Opção B — USB (telefone ligado por cabo)

Telefone detectado: liga USB + Depuração USB, depois no PC: adb reverse tcp:8084 tcp:8084 Inicia o Expo em modo USB: cd apps/mobile-user && npx expo start --port 8084 --localhost No Expo Go → Enter URL manually: exp://127.0.0.1:8084

Opção C — Tunnel (pode falhar no Windows)

cd apps/mobile-user && npm run dev:tunnel

Se ngrok tunnel took too long, usa Opção A ou B.

  1. Expo Go SDK 54
  2. Scan QR ou Enter URL manually
  3. Fecha a app antes de tentar de novo
